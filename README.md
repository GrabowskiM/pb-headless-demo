# pb-headless-demo

A TanStack Start application that renders an Ibexa Page Builder landing page through
[`@ibexa/cohesivo-sdk-react-headless`](https://github.com/ibexa/frontend-kit), used to
exercise the published packages the way an integrator would.

## Requirements

The `@ibexa/cohesivo-sdk-*` packages are public on npmjs.com, so a plain install is enough:

```sh
npm install
```

## Running

```sh
npm run dev      # development server on http://localhost:3000
npm run build    # client bundle and SSR server
npm run preview  # serve the production build
```
